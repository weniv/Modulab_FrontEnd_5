* Branch: 코드의 분기를 만들어서 협업을 원할하게 할 수 있도록 해주는 것

```
# 폴더 생성 및 이동
# VSCode로 해당 폴더 열기
# 터미널 열어 아래 명령어 실행

# git 저장소 초기화
git init

# 브랜치 확인(아무것도 없음)
git branch

# index.html 파일을 생성하고 내용을 작성합니다.
# echo . > index.html도 가능합니다. 
echo ''>index.html

# 파일을 스테이징(관리하겠다!)하고 커밋합니다.
git add .
git commit -m "1"

# 브랜치 확인(main 하나 있음)
git branch

# 브랜치 생성
git branch a
git branch b
git branch c

# 브랜치가 잘 만들어졌는지 확인합니다.
git branch

# 브랜치 이동
git checkout a

# 브랜치 이동 확인
git branch

# a 브랜치에서 작업을 합니다.
echo ''>a.js
git add .
git commit -m "a 작업 완료"

# b 브랜치로 이동합니다.
# 이동하면 a.js 파일이 없습니다.
git checkout b
echo ''>b.js
git add .
git commit -m "b 작업 완료"

# c 브랜치로 이동합니다.
# 파일을 확인해보세요! a.js, b.js 파일이 없어요.
git checkout c
echo ''>c.js
git add .
git commit -m "c 작업 완료"

# 합칠 때에는 꼭 main에 들어와 있는지 확인해야 합니다.
# 합칠 때 뜨는 에디터가 있을 텐데 메시지를 다 지워주시고 test-1, test-2, test-3 등으로 작성해주세요.
# 기본 VSCode 사용하도록 글로벌 설정 명령어
# git config --global core.editor "code --wait"
git checkout main
git merge a
git merge b
git merge c

# 합쳐졌는지 VSCode에서 확인해보세요.
# a.js, b.js, c.js 파일이 모두 있습니다.
# Source Control하단에 GRAPH 클릭해서 확인해보세요.

# 다른 브렌치 삭제
git branch -d a
git branch -d b
git branch -d c
```

* 과제:
    * a 브랜치를 만들어서 a.js 파일을 만들고 커밋하기
    * aa.js 파일을 만들고 커밋하기
    * b 브랜치를 만들어서 b.js 파일을 만들고 커밋하기
    * bb.js 파일을 만들고 커밋하기
    * c 브랜치를 만들어서 c.js 파일을 만들고 커밋하기
    * cc.js 파일을 만들고 커밋하기
    * main 브랜치로 돌아와서 a, b, c 브랜치를 합치기
    * a, b, c 브랜치 삭제하기
