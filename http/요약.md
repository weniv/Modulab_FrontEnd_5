# 웹, 인터넷, URL, HTTP, HTTPS

* 웹은 인터넷과 다릅니다. 인터넷은 철도네트워크에 비유할 수 있고, 웹은 그 위를 달리는 기차와 같습니다. 기차는 여러 기차가 있습니다. FTP, 이메일 등 여러 기차가 인터넷이라는 철도 위를 달립니다. 그 중 하나가 웹입니다.
* 이름(URL): www.google.com, 개인이나, 국가나 국제기구에서 관리합니다.
* 주소(IP): 142.250.207.100, 개인이 관리하는 체계가 아닙니다. 국제 기구가 관리합니다. 국제 기구에서 관리하는데 대행 업체가 이 기구에서 IP를 받아서 개인이나 기업에 나눠줍니다.
* 문(PORT): 142.250.207.100:80, 이런식으로 콜론이 붙여져서 들어갑니다. 80, 443, IP는 건물 주소라면 문은 건물의 문입니다. 건물에 여러개의 문이 있을 수 있습니다. 80번 문은 웹, 443번 문은 보안 웹입니다.

# 서비스 요청시 일어나는 일

1. 웹 브라우저를 엽니다.
2. 주소창에 URL www.google.com을 입력합니다.
3. 브라우저는 www.google.com이라는 주소와 여러분의 요청(이 주소 페이지를 보여줘!)을 request라는 이름으로 하나에 메시지로 묶어 만들어요.
4. 이러한 request를 네트워크로 전송하기 위해 메시지를 분할합니다.
5. 분할된 메시지를 DNS 서버로 보냅니다.
6. DNS가 우선 이 데이터를 받습니다.

DNS는 아래와 같은 데이터가 저장되어 있습니다.

| 이름           | 주소              | 문  |
| -------------- | ----------------- | --- |
| www.google.com | 142.250.207.100   | 80  |
| www.weniv.co.kr | 123.456.789.101   | 443  |

7. DNS는 www.google.com이라는 이름을 보고, 이 이름에 해당하는 주소와 문을 찾아서 브라우저에게 알려줍니다. 142.250.207.100 데이터를 넘겨주는 것이죠.
8. 브라우저는 이 주소와 문을 가지고, 여러분이 요청한 메시지를 다시 조립합니다.
9. 브라우저는 이 메시지를 인터넷망을 통해 142.250.207.100:80으로 여러분의 요청을 전송합니다.
10. www.google.com(142.250.207.100) 서버는 이 요청을 받고, 여러분이 요청한 페이지 데이터를 브라우저에게 응답(response) 메시지로 만들어 보냅니다.
11. 이 응답메시지를 브라우저가 받아서 여러분이 볼 수 있도록 화면에 렌더링(rendering)합니다.

* URL의 구성 요소
```
┌────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                              href                                              │
├──────────┬──┬─────────────────────┬────────────────────────┬───────────────────────────┬───────┤
│ protocol │  │        auth         │          host          │           path            │ hash  │
│          │  │                     ├─────────────────┬──────┼──────────┬────────────────┤       │
│          │  │                     │    hostname     │ port │ pathname │     search     │       │
│          │  │                     │                 │      │          ├─┬──────────────┤       │
│          │  │                     │                 │      │          │ │    query     │       │
"  https:   //    user   :   pass   @ sub.example.com : 8080   /p/a/t/h  ?  query=string   #hash "
│          │  │          │          │    hostname     │ port │          │                │       │
│          │  │          │          ├─────────────────┴──────┤          │                │       │
│ protocol │  │ username │ password │          host          │          │                │       │
├──────────┴──┼──────────┴──────────┼────────────────────────┤          │                │       │
│   origin    │                     │         origin         │ pathname │     search     │ hash  │
├─────────────┴─────────────────────┴────────────────────────┴──────────┴────────────────┴───────┤
│                                              href                                              │
└────────────────────────────────────────────────────────────────────────────────────────────────┘
(All spaces in the "" line should be ignored. They are purely for formatting.) 
```

* 포트 번호 범위
```
0번 ~ 1023번: 잘 알려진 포트 (well-known port)
1024번 ~ 49151번: 등록된 포트 (registered port)
49152번 ~ 65535번: 동적 포트 (dynamic port)
```
